# 🎮 Orpheus & Eurydice

### A Cooperative 2D Puzzle Platformer Inspired by Greek Mythology

A narrative-driven cooperative game that transforms a classic Greek myth into an interactive experience focused on **teamwork, timing, and emotional storytelling**.

---

## 🧭 Overview

**Orpheus & Eurydice** is a 2D pixel art platformer where two players must work together to navigate the underworld, overcome obstacles, and solve environmental puzzles.

Built with a strong emphasis on **cooperative mechanics**, the game challenges players to synchronize actions and think collaboratively to progress.

> This project explores how games can go beyond entertainment — serving as tools for engagement, storytelling, and learning.

---

## ⚡ Core Features

* 👥 **Cooperative Gameplay** — Designed for two players with interdependent mechanics
* 🧩 **Puzzle-Based Progression** — Environment-driven challenges requiring coordination
* 🎭 **Narrative Integration** — Inspired by the myth of Orpheus and Eurydice
* 🎨 **Pixel Art Visuals** — Stylized environments and character design
* 🎵 **Original Soundtrack** — Enhancing immersion and emotional tone

---

## 🧠 Design Philosophy

This project was built around a central idea:

> **Learning and engagement become more powerful when experienced interactively.**

By combining **mythological storytelling** with **game design principles**, the project demonstrates how digital games can:

* Encourage collaboration and communication
* Reinforce narrative understanding through interaction
* Create meaningful and memorable player experiences

---

## 🛠️ Tech Stack

* **Engine:** Unity
* **Language:** C#
* **Art:** Custom Pixel Art Assets (Pixel Studio)
* **Audio:** Original Sound Design & Music (Fl Studio)

---

## 🎮 Gameplay Highlights

* Players must coordinate actions (e.g., activating mechanisms, timing jumps)
* Each character plays a role in progression
* Failure and retry are part of the learning loop
* Designed with **speedrun potential** in mind
